# pleioverse: fast self-contained pleiotropy simulation and testing

A high-performance C++/Rcpp toolkit for pleiotropic genetic data,
unified around the
[pleio](https://broccolito.github.io/pleioverse/reference/pleio-class.md)
object. It provides
[`run_pleiosim()`](https://broccolito.github.io/pleioverse/reference/run_pleiosim.md)
to simulate pleiotropic multi-phenotype data,
[`run_pleiotest()`](https://broccolito.github.io/pleioverse/reference/run_pleiotest.md)
to run the full suite of multiple-association testing methods and
pleiotropy tests, and one `run_<test>()` function per individual test.

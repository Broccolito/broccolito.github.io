# Documentation Checklist

This checklist maps the requested documentation scope to concrete files
in this pkgdown site.

## Simulation Articles

Simulating genotypes: `vignettes/simulation-genotypes.Rmd`

Simulating phenotypes: `vignettes/simulation-phenotypes.Rmd`

Simulating correlated phenotypes:
`vignettes/simulation-correlated-phenotypes.Rmd`

Overlapped/non-overlapped cohorts, custom heritable correlations, custom
non-heritable correlations, and different heritabilities:
`vignettes/simulation-cohorts-correlations.Rmd`

## Workflow and Interpretation Articles

Running the full and partial test workflows:
`vignettes/running-tests.Rmd`

Combining tests with ACAT: `vignettes/combining-tests-acat.Rmd`

Understanding output columns, ordinary p-values, FDR-style quantities,
pairwise outputs, and `NA` values:
`vignettes/understanding-output-p-values.Rmd`

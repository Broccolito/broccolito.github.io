BioOKF Open Source

Biomedical Open Knowledge Format. A typed, structured open format that gives AI agents a closed vocabulary of 28 node types and 35 relationship predicates to map any source into a provenance-tracked biomedical knowledge graph. Ships as an open-source Rust stack with a scriptable CLI, an MCP server, and a desktop Studio.
